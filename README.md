# Construction Wizzards

Make this WebsiteProject Title: Development of Construction Wizzards – Multi-Vendor E-Learning, Mentorship & Professional Community Platform (Mobile App + Website)

We are looking for an experienced full-stack development team to design and develop Construction Wizzards, a comprehensive professional learning, mentorship, knowledge-sharing, and community marketplace platform.

The application must support Android, iOS, and web, with a centralized Super Admin dashboard.

Key Features and Requirements:

Dual-Role User Accounts: Every registered user can switch between Learner and Mentor using a single button, without creating separate accounts.

Online Learning Marketplace: Mentors can create, upload, price, and sell recorded courses, live classes, webinars, workshops, and offline seminars. Learners can enroll, track progress, and receive completion certificates.

Revenue Sharing: The platform earns an admin-configurable commission on course sales and eligible transactions (initially 50% admin / 50% mentor).

Subscriptions: Individual course purchases provide access to the purchased course only. Monthly or annual subscriptions can provide access to eligible courses across multiple mentors, with an appropriate revenue-sharing mechanism.

Refunds and Mentor Payments: Seven-day learner refund request window, 14-day mentor payout holding period, automated earnings calculation, payment approval, and dispute handling.

Escrow and Wallet System: Secure payment collection, transaction ledger, mentor earnings dashboard, withdrawal requests, refund processing, and admin-controlled payment release through an appropriate licensed payment provider.

Professional Discussion Forum: Members can create topics, respond, ask questions, and share images, PDFs, voice messages, documents, and other educational materials.

Community Marketplace: Members can list, buy, and sell new or used products, particularly construction-related tools, equipment, materials, and professional resources.

Community Engagement: Professional networking, member groups, events, referral rewards, exclusive offers, travel packages, gatherings, and community benefits.

User Verification: Identity verification through appropriate government-issued identification, mentor qualification/certificate verification, profile approvals, and verification badges.

Super Admin Dashboard: Complete control over users, mentors, courses, commissions, subscriptions, revenue, refunds, payouts, disputes, verification, content moderation, promotions, and analytics.

Additional Features: AI-powered course recommendations, smart search, reviews and ratings, multilingual support, push notifications, live chat, quizzes, assessments, referral programs, coupon codes, and downloadable certificates.

Technical Expectations:

Android and iOS mobile applications

Responsive website and mentor portal

Secure Super Admin dashboard

Scalable backend architecture and APIs

Payment gateway and video streaming integrations

Role-based access control and data security

Modern UI/UX design

Full source-code ownership and documentation

Development Approach:

We prefer milestone-based development, starting with the core e-learning marketplace, mentor/learner switching, payment system, subscriptions, and admin dashboard, followed by community and advanced marketplace features.

Interested developers should provide:

Relevant previous projects and portfolio

Recommended technology stack

Estimated development cost and timeline

Detailed milestone-based quotation

Third-party integration and recurring maintenance costs

Post-launch maintenance and technical support arrangements

We have a detailed Software Requirements Specification (SRS) document available for discussion with shortlisted developers.

Our objective is to build a scalable, secure, and commercially sustainable international professional learning and community platform, rather than a basic course-selling application.
